# Changelog

## 0.1.0

Initial release for DeepSeek Harness v0.1.7-alpha.1.

- Six workspace identity colors and a Default reset.
- Sidebar identity stripe and matching folder icon.
- Browser-local persistence keyed by workspace ID.
- English and Chinese interface; light and dark theme palettes.
- Native DSH footer slot and modal; additive plugin with unload cleanup.

Validated by five plugin tests, TypeScript checking, and a real DSH Web smoke test of the packed installation, selection, reload persistence, and reset. Electron has not been tested.
